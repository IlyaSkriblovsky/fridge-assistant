## Бесплатный или платный уровень Gemini API

AI выбран: [vision.md](vision.md#голос-и-команды-обрабатывает-gemini-api). На
каком уровне Gemini API работать, не решено.

- **Бесплатный.** Лимиты указаны только в AI Studio, но для десятков запросов
  в день их, скорее всего, хватит. Google использует запросы и ответы для
  улучшения своих продуктов, и их могут читать люди. Для нас это записи голоса
  из дома. Исключение: если вы в ЕЭЗ, Швейцарии или Великобритании, то и на
  бесплатном уровне действуют условия платного.
- **Платный.** Данные для улучшения продуктов не используются. Запрос стоит
  доли цента.

## Где живёт сервер

Сейчас сервер запускается на компьютере в домашней сети, и прибор ходит к нему
по локальному адресу по HTTP. Документы прошивки рассчитывают, что в итоге
сервер уедет в облако. Тогда понадобятся HTTPS и авторизация прибора, и
появятся они вместе (D5 и D8 в прошивке). Сколько стоит TLS-рукопожатие на
приборе, который просыпается ради каждого вопроса, ещё не измерено (E2 в
прошивке).

Где бы ни жил сервер, его страна должна быть в
[списке регионов Gemini API](https://ai.google.dev/gemini-api/docs/available-regions).
Судя по документации, проверяется страна машины, которая делает запрос.
России и Беларуси в списке нет.

## Хранить ли записи

Прототип сохраняет каждую запись на диск, это нужно для отладки. По замыслу из
документов прошивки настоящий сервер будет передавать звук во внешний API, а
не хранить записи. Нужно ли сохранять их, например для разбора неудачных
распознаваний, не решено.
