## HTTPS между прибором и сервером

Сервер живёт на арендованном сервере
([vision.md](vision.md#сервер-живёт-на-арендованном-сервере)) и доступен из
интернета. Прибор предъявляет ему токен
([vision.md](vision.md#один-пользователь-один-прибор-один-токен)), но ходит пока
только по HTTP, так что токен идёт открытым текстом. Поэтому за nginx-proxy
сервер отвечает и по HTTP ([server.md](server.md#за-nginx-proxy)).

Прибор просыпается ради каждого вопроса, и TLS-рукопожатие он будет платить
каждый раз. Сколько оно стоит, ещё не измерено (E2 в прошивке). Сначала замер,
потом решение (D5 в прошивке).
