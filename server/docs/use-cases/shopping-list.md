# Список покупок

Первый сценарий, ради которого затевается ассистент.

## Как сейчас

Семья ведёт список того, что купить в следующий поход в магазин, в виде общей
заметки в Google Keep. В основном там продукты, иногда товары для дома, а
иногда и то, что продаётся в других магазинах: лекарства, кошачий корм.

Кто идёт в магазин, открывает заметку и покупает по списку, сразу вычёркивая
купленное.

## Что хотим

Заметил, что в холодильнике что-то закончилось, и сказал прибору на
холодильнике, чего не хватает. Ассистент заносит это в тот же общий список.

Отсюда требования к месту, где живёт список:

- Он общий: остальные члены семьи видят добавленное в своём обычном
  приложении на телефоне.
- В нём можно вычёркивать пункты прямо в магазине.
- У него есть API, через которое сервер может добавить пункт.

## Открытый вопрос: где список и как до него достучаться

Как ассистент будет работать с заметкой, пока не решено. Говорят, что у Google
Keep с API всё плохо, но это ещё не изучалось. Возможно, со списком придётся
переехать с Google Keep на другой сервис с подходящим API.

С чего начать изучение (всё ниже не проверено):

- Официальный Google Keep API существует, но, насколько известно, только для
  аккаунтов Google Workspace. Для личного аккаунта он может не подойти.
- Есть неофициальная Python-библиотека `gkeepapi`. Она работает через
  реверс-инжиниринг внутреннего API, поэтому может сломаться в любой момент.
- Если уезжать с Keep, кандидатов надо сравнивать по требованиям выше, и
  главное из них — чтобы семье было удобно в магазине.
