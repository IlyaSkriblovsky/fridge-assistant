# Инструкции для работы с проектом

- Перед работой с `server/` прочитай `server/AGENTS.md` и следуй его инструкциям.
- Перед работой с `firmware/` прочитай `firmware/AGENTS.md` и следуй его инструкциям.
- Если задача затрагивает обе части, прочитай оба файла.
- Общие для агентов инструкции храни в `AGENTS.md`. Файлы `CLAUDE.md` рядом
  содержат только импорт `@AGENTS.md`; не дублируй в них инструкции.

## Форматирование

Python форматирует Ruff, C/C++ — clang-format. Настройки и закреплённые версии
общие для всего репозитория: `ruff.toml`, `.clang-format`,
`.pre-commit-config.yaml`. Сгенерированные `firmware/src/fonts/` и сторонний
`firmware/lib/dashboard_miniz/` исключены из форматирования C/C++.

Из корня репозитория установи Git hook (один раз для каждого клона):

```sh
uvx pre-commit==4.5.1 install
```

После этого форматтеры запускаются при каждом коммите для изменённых файлов.
Если hook исправил файлы, добавь исправления через `git add` и повтори коммит.
Чтобы отформатировать весь проект вручную:

```sh
uvx pre-commit==4.5.1 run --all-files
```

Первый запуск требует сети для установки инструментов; pre-commit управляет
ими в изолированных окружениях. В CI тот же запуск проверяет форматирование.
